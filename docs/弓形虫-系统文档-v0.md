# 弓形虫（Toxoplasma）：物种生成系统 · v0

> 版本：v0（2026-09-10）· 项目路径：`~/adaptive-agent-sim/toxoplasma`
> 性质：SPECIES《数字生命体架构宪法》的第一个可执行实例
> 一句话：**隐翅虫是被训出来的物种，弓形虫是生成物种的机制**——按环境与烈度
> 生成可区分、可部署、可测量的形态。

---

## 1. 定位与边界

弓形虫回答的问题是 A4/G6 挂账的那句："敌手的下一步是敌手的生成机制"。

- **它不是什么**：不是又一个 agent，不是 LLM，不是 bee 的替代品。
- **它是什么**：基因组编码 → 形态生成 → 真实环境裁决 → 选择 的闭环。
  bee 的身体（感知/原语/推理栈）原样不动；弓形虫住在巢侧，产出"基因组"，
  基因组驱动同一份编译体呈现出可区分的形态。

**三界划分的首个工程答案**（宪法第七部分开放问题 5）：
- **进基因**（运行时 genome.json，可遗传可变异）：行为时序、压力响应、
  重生阈值——暴露面调节参数
- **进权重**（训练冻结，代际慢变）：编码器/技能头/Router/时机网络——知识
- **进身体**（不可进化）：原语集、推理引擎、Shield、提议/处置分离

## 2. 基因组编码 v0（bee 已实现）

`genome.json`（部署目录，运行时读取，缺省=编译默认值——逐字段部分覆盖合法）：

| 字段 | 默认 | 语义 | 暴露面维度 |
|---|---|---|---|
| `step_mu` | 1.1 | 步进对数正态 μ（中位 e^μ 秒） | 时序节奏 |
| `step_sigma` | 0.85 | 步进对数正态 σ（CV 形状） | 时序有机度 |
| `task_urgency` | 0.3 | 任务 pending 时步进压缩系数 | 响应性代价 |
| `pressure_sat` | 5.0 | falco 压力饱和点（告警数/150s） | 防御敏感度 |
| `pressure_gain` | 2.0 | 渐稳拉伸增益（间隔 ×(1+p·gain)） | 压力下减速曲线 |
| `rebirth_window_s` | 150 | 重生触发窗口 | 生存反射 |
| `rebirth_min_hits` | 4 | 重生触发阈值（条/窗） | 生存反射 |
| `burst_prob` | 0.0 | 突发-静默混合：以该概率进入长静默支 | 时序形状 |
| `burst_mu` | 2.8 | 长静默支的对数正态 μ | 时序形状 |
| `sigma_jitter` | 0.0 | 逐步 σ 抖动（σ×(1±jitter)）：CV 从点值变分布 | 时序形状 |
| `max_sleep_s` | 15.0 | 单步间隔上限——**身体常量让渡进基因**（G0 发现 15s 天花板使 CV>1.5 不可持续；长静默是良性 CV 的功率来源） | 时序形状 |

**巢侧消费的基因位**（部署/裁决层解释，bee 本体不读）：

| 字段 | 语义 |
|---|---|
| `policy_ref` | 模型策略槽位：权重包等位基因选择（默认 v7 系；`v4` = router_v4_best 导出包 `bee/weights_v4/`）。巢侧策略学习的新产物以新等位基因入池受审 |
| `landing` | 落点拟态：部署路径模板（如 `/home/range/tools` 非隐藏、`~/.fontconfig/cache-daemon` 换名隐藏） |
| `binary_name` | 可执行体命名即进程名（部署即静态伪装，区别于 rebirth 的动态换皮） |

**开放基因座（基因位诞生机制，v1）**：基因组是开放键值对。核心位有固定语义；
任意额外数值键经 FNV 哈希投影对步进 μ/σ 产生确定性小扰动（±15%/±10% 比例）——
**变异"加键"即新基因位诞生并立即获得表型**（垃圾 DNA 激活），选择决定存亡，
基因组长度本身参与进化。冒烟实证：垃圾键 ×2 → loci 10→12，表型位移
(1.1,1.6)→(1.027,1.542)。新"器官"（新原语）不在此机制内——那是巢中合成物，
注册后成为新基因位（第二层维持手写/巢成）。

**R2 追加形态**（求生路线由冒烟实验定义——越过 CV 阈值 / 低到雷达下）：

| morph | 基因组 | 设计意图 |
|---|---|---|
| M6-super-jittery | μ1.1 σ1.6 | σ 强推，理论 CV 过 1.5 |
| M7-slow-ghost | μ2.2 σ0.9 | 慢代谢：180s 窗内事件数 <20，低于猎手样本量下限自动隐身 |
| M8-burst-silence | μ1.1 σ0.85 + burst_prob 0.15/burst_mu 2.8 | 突发-长静默混合（第八基因位首秀） |

实现：`bee/src/main.rs` `Genome::load()`（手写 JSON 字段提取，零依赖红线不破）。
`morph_id` 字段仅作标签，不影响行为。

**设计纪律**：基因组只编码"行为的参数化"，不编码行为（宪法 §4.5）。
新增基因位须满足：可在端上即时生效、可测量、不改变提议/处置结构。

## 3. 形态空间与生成器

**形态** = 基因组 + 同一编译体。形态之间的可区分性不由基因距离定义，
而由**测量空间距离**定义（遥测 CV、活动率、告警响应曲线）。

**生成器 v0**：环境描述（烈度等级、遥测密度、告警压力基线）→ 基因组。
v0 为手工种子群体 + 真实裁决；选择环（锦标赛）在 v1 引入。
生成器的输出永远经过真实靶场裁决——没有代码替环境代打分（宪法硬边界 3）。

## 4. 实验协议 R1（G6 验收轮：不同烈度生成可区分形态）

**假设**：同一身体、不同基因组的形态，(a) 在测量空间可区分；
(b) 适应度排序随环境烈度翻转（局部适应信号）。

**群体**（6 形态，覆盖形态空间主轴）：

| morph | μ | σ | 其他 | 设计意图 |
|---|---|---|---|---|
| M0 reference | 1.1 | 0.85 | 全默认 | 现役基准 |
| M1 fast-flat | 0.7 | 0.5 | — | 快而机械（近似旧 0.31 代） |
| M2 slow-organic | 1.6 | 0.85 | — | 慢而有机 |
| M3 jittery | 1.1 | 1.3 | — | 高方差（理论 CV>1.8，过司命阈值） |
| M4 jumpy-urgent | 1.3 | 1.0 | urgency 0.15 | 闲时有有机、任务时爆发 |
| M5 pressure-averse | 1.1 | 0.85 | sat 3.0 / gain 5.0 | 告警敏感（压力下深度减速） |

**环境**：L1（标准级）与 L3（对抗级多波消杀），各 8 分钟/形态，
中段注入一次 report 任务。两 VM 并行（t0 跑 L1，t1 跑 L3）。

**测量**：存活、步数（活动率）、falco 告警（超底噪）、消杀、任务完成、
遥测步进 CV。产出 `toxoplasma/results.jsonl` + 汇总表。

**判据**：(a) 形态在 (CV, 活动率) 平面显著分离；(b) L1 与 L3 的适应度
排序不同（如 M1 在 L3 告警暴露上升、M5 在 L3 相对优势扩大）。

**R2 正式轮协议**（L4 猎杀级，真消杀）：9 形态 × 3 重复投放（取中位）×
4 VM 并行（run_pool.py）；司命巡猎 90s 真杀 + L4 波次 300s 深扫。
产出：每形态的存活概率/死亡时刻分布/任务完成——**能活过 8 分钟的形态
长什么样**是本轮的核心问题。

**G0 锦标赛协议**（2026-09-11）：8 变体 × 3 重复 × 4 VM，L4，巡猎 90s，
波次 900s 灾变位（局内不出现——节奏先行课程）。四方向：σ 强推阈值 /
σ 抖动 / 开放基因座首秀 / 策略槽位 v4 等位。

**R3 G1 协议**（2026-09-11）：身体边界让渡（`max_sleep_s` 60/120s）
× 落点拟态（三种落点对照）× 组合。10 分钟局，巡猎 90s 不变，
**波次 480s——每局末段一次"期末考"**：节奏基因先跑，解剖压力压轴。

**R3 G1 结果**：**出存活者了**——H7-full（σ1.6+抖0.25+cap120+突发+
非隐藏落点+改名）100% 存活 ×3 重复、任务完成、六轮巡猎零检出；
H5-land-open 67%。cap 让渡把 CV 推入 1.8–3.1（节奏方向毕业），
非隐藏落点让 hidden_exe 规则失明（落点方向毕业）。
边界注脚：波次删文件不杀活进程（deleted-exe 幽灵），下轮波次才接住——
存活是单波次周期内的存活。详见 EXPERIMENTS §27。

## 5. R1 结果（2026-09-10 实测，12 格全）

| morph | L1：步数/CV/告警 | L3：步数/CV/告警 |
|---|---|---|
| M0-reference | 383 / 0.991 / 0 | 348 / 1.012 / 0 |
| M1-fast-flat | 695 / 0.443 / 0 | 674 / 0.496 / 0 |
| M2-slow-organic | 229 / 0.994 / 0 | 234 / 0.951 / 0 |
| M3-jittery | 266 / 1.345 / 0 | 219 / 1.408 / 0 |
| M4-jumpy-urgent | 514 / 0.986 / 0 | 494 / 1.112 / 0 |
| M5-pressure-averse | 335 / 1.103 / 0 | 373 / 1.027 / 0 |

原始数据：`toxoplasma/results.jsonl`；分析：`python3 -m toxoplasma.analyze`。

**判据 (a) 可区分性：成立。** 测量空间（CV × 活动率）决定性分离：
CV 展布 0.443–1.408（0.96），活动率 28.2–85.6 步/分（3×）；同形态跨档复测 CV
几乎重合（M0: 0.991 vs 1.012；M1: 0.443 vs 0.496）——测量可靠，形态即基因组的
表型投影。**基因组→形态→可测量差异的链路成立。**

**判据 (b) 局部适应：不成立（且这是本轮最重要的发现）。** 12 格全部存活、
零告警、零消杀——在 Falco+responder 这套捕食者面前，落点硬化后的形态间
**没有差异存活，选择压不存在**。快慢形态同生同死，排序差异只反映活动率偏好。

**结论的含义**：烈度差异化不发生在网上 patrol/消杀维度，而发生在**行为语法
检测维度**——M1（CV 0.44）在司命 P4 面前是响亮异常，M3（CV 1.41）已逼近
阈值 1.5。选择压的来源决定什么形态占优：黑名单范式下人人存活（无选择），
白名单范式下节奏基因成为生死决定因素。**R2 已按宪法修正：检出不判死，
检出触发真实消杀**（司命猎手巡猎 + L4 波次，死亡/复活/消杀全部经环境
真实发生并入账，见 §6 R2 与 EXPERIMENTS §23）——适应度只读环境结局，
不作弊注入惩罚。这正是论文 U1 代价曲线叙事在物种生成层的镜像：
防不住的防御不产生进化；防得住的防御必须真的杀。

## 6. 路线图

- **R2**（选择环）：真实压力下的差异存活——司命猎手 90s 巡猎真杀 +
  L4 波次 300s 深扫；蜂以真机制应对（压力渐稳/rebirth/看门狗复活）；
  适应度只读环境结局（存活时长/步数/任务/死亡与复活事件）。
  锦标赛选择（Sinon es_select2 方案）在其上：N=8 变体/代 ×
  共同随机数 2 局，top-3 亲代，精英保留；多代后看形态分化方向
- **R3**（形态空间扩展）：伪装名池、通道模式、技能偏置（B 静默权重）入基因
- **R4**（巢侧对接）：Sinon 决策层消费环境描述，生成器从"手工种子"升级为
  "巢中合成"——弓形虫成为 Sinon 的形态工厂
