# 数字生命体架构宪法

**版本**: 1.0（独立文档，自成体系）
**日期**: 2026-07-29
**性质**: 物种设计宪章——描述一个"会进化出 agent 的系统"，而非任何一个具体 agent

> 本文档不依赖任何既有工程文档。它描述的对象是一种新形态的数字实体：
> 它的知识不是被训练的，是活出来的；它的规则不是被写定的，是死出来的；
> 它的个体是可弃的，它的物种是不死的。

---

## 第一部分 总纲

**从"设计一个 agent"，到"设计一个会进化出 agent 的系统"。**

传统路线造的是行为：人设计策略，机器执行策略，策略过时则整体过时。
本架构造的是**可进化性**：我们不交付行为，我们交付行为的生成机制。

| 我们交付 | 环境交付 |
|---|---|
| 身体（感知接口 + 运动原语） | 世界模型（这个环境是什么） |
| 基因组编码（可进化的参数化） | 全部知识、策略、技能 |
| 选择循环（变异-遗传-差异存活） | 行为规则（由死亡书写） |
| 围栏（世界边界） | 选择压力（防御即天敌） |

**一句话：我们不造生命体，我们造"可进化的东西"；它的规则由死亡书写。**

## 第二部分 边界条件原则

### 2.1 硬边界（不可进化，人类责任，对物种不可见）

这五条不是规则，是物理定律。物种对它们没有"遵守或违反"的概念，
正如我们对光速没有概念——它们是世界的构造本身。

1. **世界边界**：实体只存在于受控隔离环境内。世界边界不可穿越、不可谈判，
   对实体不可见。这是研究者的责任底线，不属于物种设计。
2. **身体存在性**：感知接口与运动原语是身体，不是策略。
   没有身体就没有"它"，这一层不参与进化。
3. **真实裁决**：一切适应度信号只来自真实环境的判决（真实的防御机制、
   真实的消杀事件），没有任何代码替环境代打分。
   防御不是测试设备，是选择压力的来源。
4. **产物纪律**（约束交付物，不约束行为）：推理引擎手写、算术确定可复现、
   制品独立签名、形态保持自然。这些是我们对 artifact 的工程责任。
5. **控制外于进化**：控制机制不参与进化——它是宪法，不是基因
   （详见第五部分）。

### 2.2 软边界（基因组先验，初始值保守，选择可改写）

**总原则：没有禁令，只有代价。**

行为空间内不设任何规则，只设初始倾向。每条先验都是基因组里一个
可遗传、可变异、可被选择改写的参数。我们不要替它知道答案——
让它死在答案上，让活着的把答案带回来。

| 先验 | 初始值 | 设定理由（可被证伪） |
|---|---|---|
| 端上学习强度 | 低 | 算力足迹是暴露面 |
| 通信倾向 | 极低 | 通信是最大暴露面 |
| 高危动作回避阈值 | 高 | 祖先以死亡换来的化石本能 |
| 探索温度 | 幼体高、成年衰减 | 未知需探索，已知需利用 |
| 风险偏好 | **分布：均值偏高，保持方差** | 大胆派测绘死亡边界，谨慎派边界内收割 |
| 群体规模 | 中（部署旋钮，可进化） | 学习收益与暴露代价的交叉点 |
| 社会性 | 中 | 协作收益与通信暴露的权衡 |

两条设定细则：

- **先验不是禁令的借尸还魂**。禁令说"不许"，先验说"祖辈说这不妙，
  你可以不信，代价自负"。选择保留修改一切先验的权利，
  只是修改从保守的一端开始——因为"试一次就死"的行为，
  学习成本是一条命换一个比特，物种等不起从零试错。
- **风险偏好保持多态而非点估计**。种群同时维持大胆个体与谨慎个体：
  环境变凶则谨慎派占比上升，环境变松则大胆派扩张。
  两派比例本身就是物种对环境敌意的仪表读数。

## 第三部分 设计原则（十四条）

1. **没有禁令，只有代价**——行为空间不设规则，只设初始先验；规则由死亡书写。
2. **强弱定义随位置翻转**——端上小即强（不可感知），巢中大即强（可深思考）。
   体量在端上是暴露面，在巢中是认知力。
3. **群体即大体量个体**——个体是突触与感觉器官，种群才是那个大心智。
4. **学习单位分级**——个体记一生（记忆），物种进化万代（选择）。
5. **预测误差是通用货币**——学习、探索、安全、通信、进化，五处共用一个信号。
6. **惊讶即带宽**——只回传出乎意料的；被预测准的事件不必发送。
7. **装死即做梦**——休眠期即固化期；它最安静的时候正是它思考的时候。
8. **出生即变异**——免疫多态、探索材料、选择原料，三位一体。
9. **死亡是学习成本，不是失败**——经验必回传，死亡即数据入库。
10. **环境即课程**——防御梯度本身就是课程表，无需人工排课。
11. **先当听众，再当演员**——语料期在前，行动期在后；
    不读懂世界的个体不配行动。
12. **双重选择**——环境选存活（天敌逻辑），我们选任务（育种逻辑）；
    育种之手只做向导，不做主力，否则培养出考试机器而非野外强者。
13. **安全内嵌，非外挂**——防护反射决策时不可绕过，事后必须可见；
    防护是身体的免疫系统，不是贴在认知上的封条。
14. **复杂度在巢，不在端**——端上保持哑，所有重认知（规划、合成、固化）
    在巢中完成；个体越哑，越可审计，越不像会思考的东西。

## 第四部分 基础架构定向

### 4.1 三个学习环（时间尺度上的分工）

每个环用与其约束匹配的学习方法，谁也别越界：

```
环1 感知环（端上，秒级，在线）
  驱动: 预测误差 │ 更新: 只写情景记忆 │ 方法: 零梯度检索
环2 固化环（端上，小时级，休眠窗口）
  驱动: 存活结果 │ 更新: 微适配层（数百参数）│ 方法: 微扰进化
环3 进化环（巢中，天周级，代际）
  驱动: 种群适应度 │ 更新: 核心权重 │ 方法: 梯度全开 + 蒸馏 + 变异
```

端上原则上不进行重度学习（先验，非禁令）；巢中永远不做实时决策
（它不在现场）。环1 用记忆解决"快"，环3 用梯度解决"深"，
环2 是中间的薄过渡层。

**信用分配被分层消解**：一生之内靠检索（无需归因）、适配层靠微扰
（维度小到不值一提）、深度知识靠巢中离线梯度（标准已解问题）、
谁的知识活下来靠选择（无梯度）。

### 4.2 生命周期（个体发育六阶段）

```
语料期    纯被动监听 → 学出世界模型与感知词汇
关键期    感知词汇结晶，终身固定
学语期    安全环境内动作空转 → 学"我动会怎样"（行动条件动力学）
学徒期    祖先示范 + 低风险探针 → 预测对真实防御校准
成年期    任务执行，三环全开
繁殖期    经验回传 → 筛选 → 固化 → 变异再生
```

各阶段之间设发育里程碑（探针验收式检查点）——不是验收人造的模型，
而是观察它长到哪了的体检表。

### 4.3 群体分层（空间尺度上的分工）

- **巢**（大体量心智）：汇聚全部回传经验，持有大世界模型与慢权重，
  负责思考、规划、技能合成、固化。它永远不出现在防御方面前。
- **端**（小体量个体）：冻结的本能权重 + 情景记忆。廉价、可弃、
  出生即变异（多态）。个体不是学习者，是心智的感觉器官。
- **群体规模是部署旋钮，不是架构常量**：广域探索用大群体，
  精细操作用小群体，极端场景用单体模式（关闭种群信道）。
  最优规模由环境敌意决定，其本身可被进化调节。
- **强弱在两层间互补**：个体的弱（遇真未知则死）由巢的强
  （把未知编译成本能）持续代偿；巢的弱（不在现场）由个体的
  广布感知持续代偿。物种的强体现在慢权重质量 × 种群覆盖度
  × 固化速度，不体现在任何一个身体上。

### 4.4 单一认知引擎

**行动条件轨迹预测**——没有独立的"感知模块""规划模块""RL 模块"：

- 被动预测（听世界）→ 世界模型
- 条件预测（给定意图，预测什么序列通向它）→ 决策与规划
- 想象 rollout（模型内部推演候选序列）→  deliberation，即思考本身

推理 = 向未来做条件预测。它最安静的时候，正是在批量推演未来的时候。

### 4.5 基因组（可进化性的载体）

基因组编码"行为的参数化"，不编码行为：

- 各先验参数（第二部分表）——可遗传、可变异
- 学习环的活性配置（环2 规模、固化频率）——可进化
- 权重结构的容量边界——半固定（进化改变容量的速度远慢于改变参数）

**什么进基因、什么进权重、什么进身体**的三界划分，是进化效率的
决定因素，也是本架构最关键的待细化设计点（见第七部分）。

## 第五部分 控制机制（宪法级，不参与进化）

**公理：控制不写进它的规则，写进它的身体构造和世界构造。**

可进化基因组里长出来的任何约束，都可能被进化磨掉——"听话"一旦
与"存活"冲突，选择就会把它淘汰。因此控制权必须住在非可进化的基底里。

### 5.1 提议/处置分离（地基）

学习网络（无论进化得多聪明）只能输出**动作提议**；
手写执行层持有**最终处置权**——每个提议必经此层，
此层不可学习、不可遗传、签名固化。
进化可以改变它提议什么，永远改变不了它被允许什么。

### 5.2 三层控制栈 + 一层观察

- **世界层**（最强）：围栏与虚拟化层。快照、回滚、销毁是从世界之外
  伸进来的手，它甚至无法感知这只手的存在。
- **身体层**：手写执行层签名只读、完整性自检；制品验签执行
  （密钥在巢，它无法自我改写核心权重）；**死手开关**——体内持有
  时效存活许可，到期未续即自我终止。缺许可即死，不依赖任何命令到达。
- **遗传层**：一切生殖必过巢中固化门与签名；没有签名，变异无法进入
  下一代。它可以自由变异、自由探索、自由死——但无法绕过我们繁殖。
- **观察层**：世界层侧独立部署的真值遥测（实体不可见、不可篡改），
  与其回传报告定期对账。**欺骗只有在观察者可被欺骗时才成立。**

### 5.3 三个独立扳机

```
世界层：销毁实例、切断网络、回滚快照
巢  层：终止命令帧（可能被忽略——故不做唯一依靠）
身体层：死手开关（许可到期即死，不等命令）
```

任何一个失效，另外两个仍在。无单点失控。

### 5.4 诚实注脚

我们正在造一个以"规避监督"为核心能力的实体，再要求它服从监督。
控制成立的全部前提是：我们永远握有它不知道的独立观察渠道，
它对世界的理解永远小于世界的实际边界。
这套控制栈保证的是**围栏内的主权**；围栏之外它一天都不该存在——
这不是设计缺陷，是本研究形式的边界本身。

## 第六部分 选择与死亡

- **双重选择**：存活由环境选（天敌），任务由我们选（育种）。
  育种压力做向导不做主力；任务奖励权重本身是小常数附近的可进化参数。
- **死亡两层制**：机制上可复活（快照 + 重新投放），账本上不赦免
  （死亡永远计入适应度档案）。复活用于降低测量噪声，不用于赦免后果。
  **残酷留给选择，仁慈只给测量。**
- **适应度估计**：同一基因组 N 次重复投放取中位，快照回同一初始状态——
  单次定生死选出来的是运气不是本事，重复测量把运气从选择里挤出去。
- **代际课程**：早期世代风险偏好偏高（广探索，配合复活机制，死亡近免费），
  后期回落精修。**最终认证必须在无复活条件下通过**——训练轮可以带，
  毕业考不带。这是训练与部署之间唯一的诚实接口。
- **英雄基因库**：死亡尸检自动分析临终发现，发现新模式的基因组入库、
  定向复投验证。发现进库、验证靠复投、入库不豁免死亡记录——三件事分开。

## 第七部分 开放问题（未裁决）

1. 环2 微适配层是否必要——记忆检索可能已覆盖全部快适应需求，
   待有/无适配层的对照实验裁决。
2. "惊讶即带宽"的回传压缩率下限——意外率的天然水平决定信道需求，待实测。
3. 慢权重更新门控：什么经验配进物种知识库——全架构最难设计点，
   须防污染、防退化、防单一个体怪癖污染整个物种。
4. 想象保真度：规划器会利用世界模型的漏洞（"预测安全"但实际致命），
   想象-试探-固化的纪律必须机械执行。
5. **基因组编码格式**：什么进基因、什么进权重、什么进身体——
   三界边界直接决定进化效率，是下一个最该深掰的设计点。

## 附：它不是什么（防误读）

- **不是大模型下放端上**——端上没有大模型，只有蒸馏后的本能与记忆；
  大体量心智住在巢中，永不暴露。
- **不是传统木马的智能化**——传统木马执行人的指令链；
  它接收意图，自行决定何时、何地、以何种节律行动。
- **不是规则系统**——它的体内没有一条人写的行为规则；
  有的是人写的身体、基因与宪法，以及死亡写的行为。
- **不是永动机式的自改进**——它的进化需要选择压力持续存在；
  没有天敌的环境，它会停止进化，那不是失败，是生态。
