# Security Policy

## Scope

Whetstones Lab is a **de-weaponized research release**: it contains
measurement data, genomes, telemetry, training code, defensive detection
rules, and trained checkpoints. The offensive payload, deployable binaries,
C2 infrastructure, and real offensive primitives are intentionally withheld.

## Dual-Use Terms / 双重用途声明

**For research and defensive use only. Any illegal use is not supported or
authorized. Offensive primitives and payloads are intentionally withheld.
You must comply with applicable laws in your jurisdiction.**

**仅支持研究与防御用途，不支持、不授权任何非法用途。真实原语与载荷被有意移除。使用者须遵守当地法律。**

## Reporting a Vulnerability or Leak

If you believe this release contains:

- residual credentials, keys, or sensitive infrastructure details, or
- content that meaningfully lowers the bar for offensive misuse,

please report it **privately** to: **dahanxinshen@outlook.com**

Please include the file path and a short description. We will acknowledge
within 7 days and remediate verified issues in a follow-up commit.

## Abusive Use

Do not use this repository to plan, prepare, or execute unauthorized access
to any system. Nothing in this repository grants permission to test systems
you do not own or lack written authorization to assess.
